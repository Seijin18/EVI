Política de Privacidade — EVI

Última atualização: 19 de outubro de 2026.

Quem usa o EVI

O EVI é um assistente pessoal operado por uma única pessoa, o seu autor, em um computador próprio. Ele só acessa dados da conta Google do proprietário, que o conectou e autorizou.

Dados do Google que o EVI acessa

  • Google Agenda: ler e criar eventos, para listar a agenda e agendar compromissos pedidos pelo proprietário.
  • Google Tarefas: ler e criar tarefas.
  • Gmail: ler cabeçalhos e trechos de mensagens da caixa de entrada para resumi-la e destacar o que exige ação, e mover mensagens para a lixeira quando o proprietário pede explicitamente. O EVI não envia e-mails.
  • Google Contatos (somente leitura, quando habilitado): ler nomes e telefones para identificar contatos.

Como os dados são usados e armazenados

Os dados são usados apenas para atender aos pedidos do próprio proprietário (por exemplo, o resumo diário e as respostas a perguntas sobre sua agenda e e-mail). Os dados ficam no computador do proprietário (banco de dados e arquivos locais). Os tokens de acesso ficam armazenados localmente, na instalação do proprietário, e nunca em um servidor do autor.

Compartilhamento com terceiros

O EVI não vende nem compartilha dados com terceiros para publicidade e não os usa para treinar modelos próprios. Para gerar respostas, trechos de conteúdo podem ser enviados a provedores de modelos de linguagem (Google Gemini API e OpenRouter, este com política de retenção zero e sem uso para treinamento) estritamente para produzir a resposta pedida pelo proprietário. Nenhum dado é divulgado a outras pessoas.

Uso limitado

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Retenção e exclusão

O proprietário pode apagar os dados locais a qualquer momento e revogar o acesso do EVI em myaccount.google.com/permissions.
